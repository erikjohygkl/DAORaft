# DAORaft

A simple DAORaft Controller for Scalable design.

With DAORaft, you get a lightweight tool that stays out of your way.

**What you get**

- A simple DAORaft Controller for Scalable design

## Key Features

- A simple DAORaft Controller for Scalable design

## Technology Stack

- python
- python framework (Flask/Django/FastAPI or equivalent)
- Pytest for testing

## Installation

1. Clone the repository: `git clone https://github.com/minjukimdev/DAORaft.git`
2. Install dependencies: `pip install -r requirements.txt`
3. Run the test suite: `pytest`

## Configuration

Most behavior is controlled via command-line flags:
- `--verbose`: enable detailed logging
- `--config <path>`: point to a custom config file
- `--dry-run`: preview changes without applying them
